# The Kernels – CPU & Disk Scheduling Simulator


## Java Version
- Java Development Kit (JDK): 25


## How to Run
1. Make sure Java (JDK 25 or compatible version) is installed on your computer.
2. Download `TheKernels.jar` from this repository.
3. Run the application using either method:
   - **Option 1:** Double-click `TheKernels.jar` to launch the application.
   - **Option 2:** Open a terminal or command prompt in the folder containing the JAR file and execute:

     ```bash
     java -jar TheKernels.jar
     ```
